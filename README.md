# 🧊 OxyONE Master (`OxyONE_Master`)

Dépôt central et de coordination pour l'écosystème **OxyONE / SSCI Solution of Cold**. Ce dépôt consolide la documentation globale, les spécifications, les configurations et la gouvernance technique des différents modules de la plateforme (applications Flutter, backends cloud et services IoT).

---

## 🏗️ Structure de l'Écosystème
* **`oxyone-cloud`** : Infrastructure globale et services cloud.
* **`oxyone-app`** : Application principale de supervision.
* **`cold_storage_app`** : Module de gestion des chambres froides.
* **`Smart-tracking-syst-m`** : Système de suivi et télémétrie IoT.
* **`backend-ssci-cloudrun`** : Microservices API et traitement des données.
* **`Coldservice`** : Plateforme web de design et maintenance.

---

## 🚀 Déploiement GCP
Projet géré et administré via **Google Cloud Shell**.
